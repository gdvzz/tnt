## 实验简介
<br>
当前机械臂样例程序，可输入自然语言，比如“grab blue cube and move to 0,200”（抓取蓝色方块，放到 0，200）（x=0，y=200），控制机械臂做相关动作。通过本实验，实现用麦克风说话，比如“抓取蓝色方块，放到 0，200”，也可以控制机械臂做相关动作。

### 任务

可有多种方式实现语音控制。比如：

1、云端做 ASR（Automatic Speech Recognition，自动语音识别）;<br>
2、本地做 ASR<br>
3、录制 FLAC 语音文件。现有程序可处理 FLAC 文件。<br>
4、其他方式。<br>

**✳️ 要求：**

- 至少实现 2 种方式。
- （可选）增加必要的语音播报。

### 主要硬件
<!-- <br> -->
- **主机**：NVIDIA Jetson Orin NX 16GB（Ubuntu / JetPack 5.1.3）
- **屏幕**：HDMI 接口屏幕
- **外设**：USB 鼠标键盘
- **机械臂**：可抓取积木的教学用机械臂
- **麦克风 + 喇叭**

## 验证现有demo

**1、创建实验目录**

在开发板上创建实验目录，比如：

```bash
mkdir -p ~/vvc1113
```

> `~` 表示 jetson 用户的 HOME 目录，默认是 `/home/jetson`，因此完整的路径是： `/home/jetson/vvc1113`。

**2、下载现有demo**

下载链接：[viki1113.zip](./viki261113.assets/viki1113.zip)

> 在开发板上用浏览器下载，通常保存在目录 `~/Downloads` 中。`~` 表示 jetson 用户的 HOME 目录，默认是 `/home/jetson`，因此完整的路径是： `/home/jetson/Downloads`。

并移动到 `~/vvc1113`：

```bash
mv ~/Downloads/viki1113.zip ~/vvc1113
```

解压缩：

```bash
unzip ~/vvc1113/viki1113.zip
```

> 解压缩后，会生成子目录 `~/vvc1113/viki1113`，现有 demo 在该子目录中。

**3、运行现有demo**

切换到现有 demo 所在目录：

```bash
cd ~/vvc1113/viki1113
```

激活 demo 运行所需虚拟环境：

```bash
conda activate viki
```

运行 demo：

```bash
python3 agent.py
```

在机械臂前方，放置几个颜色积木，并尝试抓取移动蓝色方块。在 `<USER>:` 提示符后输入 `grab blue cube and move to 0,200`

```text
python3 agent.py
WARNING: Carrier board is not from a Jetson Developer Kit.
WARNNIG: Jetson.GPIO library has not been verified with this carrier board,
WARNING: and in fact is unlikely to work correctly.
<USER>:grab blue cube and move to 0,200
```

## 实验建议

### 方式1：云端ASR

**1、原理**

- 将 jetson 开发板外接的 USB 麦克风的语音，上传云端 ASR 做识别。
- 将识别到的文字，复用现有方式控制机械臂做相关动作。

**2、流程**

以下是建议的流程，供参考：

- 按 Enter（回车键） 开始说话；
- 再按 Enter 结束（或静音 1.2 秒自动结束）；
- 录音转成 FLAC，上传到 `voice_control.cloud.endpoint`；
- 识别文本先显示，语音播报（可选）“识别到……”，确认后才让机械臂执行。

**3、其他信息和提示**

- 云端ASR的 endpoint，可在 `api.py` 中找到，是：`qwen_audio_url="https://llm.educg.com/svc/AfW1gQzE-1/audio"`
- 使用麦克风时，建议指定麦克风名称 `Q5+`，而不是指定 index。因为插拔麦克风时，可能导致 index 变化。
- 如果效果不佳，可以考虑指定麦克风的相关阈值，以免将环境音收录进去。

### 方式2：本地ASR

和“方式1：云端ASR”很类似，只是用本地模型做 ASR。

本地 ASR 模型有很多，可以自由选择。实验室已下载 `sherpa-onnx` 模型，供参考。

```bash
models1113/
└── [4.0K]  sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17
    ├── [  71]  LICENSE
    ├── [ 104]  README.md
    ├── [5.8K]  export-onnx.py
    ├── [228M]  model.int8.onnx
    ├── [4.0K]  test_wavs
    │   ├── [224K]  en.wav
    │   ├── [225K]  ja.wav
    │   ├── [144K]  ko.wav
    │   ├── [161K]  yue.wav
    │   └── [175K]  zh.wav
    └── [308K]  tokens.txt
```

可执行以下命令，将模型复制到自己的开发板上：

```bash
scp -r jetson@172.18.145.207:~/models1113/* ~/vvc1113/models
```

> 将 172.18.145.207 上的 jetson 用户的 HOME 目录下 models1113 子目录下的文件（以及下级子目录），复制到自己开发板上的 HOME 目录下的 vvc1113/models 目录中。

> 确保自己的开发板上 `~/vvc1113/models` 目录已创建。可执行命令创建：`mkdir -p ~/vvc1113/models`。

> jetson 用户的密码是：`yahboom`。

### 方式3：录制 FLAC 语音文件

开两个终端，一个负责录音，一个负责识别。

录音工具会：

- 用 `sounddevice` 录音，没有时自动回退 `arecord`；
- 检测到说话后开始缓存，静音 `silence_seconds` 后结束一句；
- 写入临时 FLAC，再 `os.replace` 原子替换 `Recording.flac`；
- 监听端只看 mtime + 大小，因此不会读到半个 FLAC 文件。
