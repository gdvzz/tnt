## 实验简介
<br>
当前机械臂样例程序，可输入自然语言，比如“grab blue cube and move to 0,200”（抓取蓝色方块，放到 0，200）（x=0，y=200），控制机械臂做相关动作。通过本实验，实现用麦克风说话，比如“抓取蓝色方块，放到 0，200”，也可以控制机械臂做相关动作。

### 任务

可有多种方式实现语音控制。比如：

1、云端做 ASR（Automatic Speech Recognition，自动语音识别）;<br>
2、本地做 ASR<br>
3、录制 FLAC 语音文件。现有程序可处理 FLAC 文件。<br>
4、其他方式。<br>

**✳️ 要求：**

- 至少实现一种方式。
- 鼓励方式1、2、3，都实现。
- （可选）增加必要的语音播报。

### 主要硬件
<!-- <br> -->
- **主机**：NVIDIA Jetson Orin NX 16GB（Ubuntu / JetPack 5.1.3）
- **屏幕**：HDMI 接口屏幕
- **外设**：USB 鼠标键盘
- **机械臂**：可抓取积木的教学用机械臂
- **麦克风 + 喇叭**

## 实验建议



### 验证现有demo

**1、创建实验目录**

在开发板上创建实验目录，比如：

```bash
mkdir -p ~/vvc1113
```

> `~` 表示 jetson 用户的 HOME 目录，默认是 `/home/jetson`，因此完整的路径是： `/home/jetson/vvc1113`。

**2、下载现有demo**

下载链接：[viki1113.zip](./viki261113.assets/viki1113.zip)

> 在开发板上用浏览器下载，通常保存在目录 `~/Downloads` 中。`~` 表示 jetson 用户的 HOME 目录，默认是 `/home/jetson`，因此完整的路径是： `/home/jetson/Downloads`。

并移动到 `~/vvc1113`：

```bash
mv ~/Downloads/viki1113.zip ~/vvc1113
```

解压缩：

```bash
unzip ~/vvc1113/viki1113.zip
```

> 解压缩后，会生成子目录 `~/vvc1113/viki1113`，现有 demo 在该子目录中。

**3、运行现有demo**

切换到现有 demo 所在目录：

```bash
cd ~/vvc1113/viki1113
```

激活 demo 运行所需虚拟环境：

```bash
conda activate viki
```

运行 demo：

```bash
python3 agent.py
```

在机械臂前方，放置几个颜色积木，并尝试抓取移动蓝色方块。在 `<USER>:` 提示符后输入 `grab blue cube and move to 0,200`

```text
python3 agent.py
WARNING: Carrier board is not from a Jetson Developer Kit.
WARNNIG: Jetson.GPIO library has not been verified with this carrier board,
WARNING: and in fact is unlikely to work correctly.
<USER>:grab blue cube and move to 0,200
```
