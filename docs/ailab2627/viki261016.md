## 一、实验目标

大模型在垂直领域有两个突出问题：**幻觉**（编造门票、预约规则）和**知识陈旧**（不知道最新政策）。

本实验用 **RAG（检索增强生成）** 缓解，并对比三种集成方式：

| 版本 | 核心机制 | 难度 |
|---|---|---|
| **V1 固定 RAG** | 每次提问无条件检索 | ⭐⭐ |
| **V2 Tool-RAG** | RAG 封装为工具，Agent 自主调用 | ⭐⭐⭐ |
| **V3 Agent-RAG** | V2 + 关键词重排 + 缺失追问 + Self-Reflection | ⭐⭐⭐⭐⭐ |

**最终交付**：在 Jetson Orin NX 上完成部署，并通过 Chainlit Web 界面演示。

## 三、实验原理

### 3.1 RAG 基础链路

```md
文档 → 切分 → Embedding → 向量库 → 相似度检索 → Top-K → 注入 Prompt → LLM 生成
```

本实验各环节：

| 环节 | 实现 |
|---|---|
| 切分 | `build_knowledge.py` 按段落+句号切 |
| Embedding | `core.embed()` → Ollama `nomic-embed-text` |
| 向量库 | `chromadb.PersistentClient`（本地持久化） |
| 检索 | `core.retrieve()` |
| 生成 | `core.chat()` → 商汤 `sensenova-6.8-flash-lite` **或** Ollama `qwen2.5:3b` |

### 3.2 ReAct 循环

```md
Thought → Action → Observation → Thought → ... → Final Answer
```

LLM 通过文本化思考，**自主决定是否调用工具、调哪个、传什么参数**。

### 3.3 Function Calling 协议

本实验使用 OpenAI 兼容的 function calling：

**请求体**：

```json
{
  "model": "sensenova-6.8-flash-lite",
  "messages": [{"role": "user", "content": "无锡灵山大佛学生票多少？"}],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "search_travel_knowledge",
        "description": "检索本地旅游知识库...",
        "parameters": {
          "type": "object",
          "properties": {
            "query": {"type": "string"},
            "city": {"type": "string"}
          },
          "required": ["query", "city"]
        }
      }
    }
  ]
}
```

**响应体**：

```json
{
  "message": {
    "role": "assistant",
    "content": "",
    "tool_calls": [
      {
        "function": {
          "name": "search_travel_knowledge",
          "arguments": {"query": "灵山大佛学生票", "city": "无锡"}
        }
      }
    ]
  }
}
```

Agent 拿到 `tool_calls` 后执行工具，把结果作为 `role="tool"` 消息回填，再让 LLM 继续生成。

### 3.4 三种集成方式的差异

| 方式 | 检索时机 | 优点 | 缺点 |
|---|---|---|---|
| V1 固定 RAG | 每轮必检索 | 简单稳定 | 闲聊也检索，浪费 |
| V2 Tool-RAG | Agent 判断 | 节省算力，工业主流 | 依赖模型判断 |
| V3 Agent-RAG | V2 + 反思 | 降低遗漏 | 慢，复杂度高 |

## 五、V1 / V2 / V3 递进实现

> 以下说明对两个版本均适用。差别只在对话模型是商汤还是 Ollama。

### 5.1 V1 固定 RAG —— "每次都查"

**代码位置**：`v1_fixed_rag.py`（约 40 行）

**核心逻辑**：

```python
def ask(query):
    docs = retrieve(query, k=3)              # 无条件检索
    context = "\n\n".join(d["content"] for d in docs)
    prompt = f"知识库：\n{context}\n\n问题：{query}"
    return chat([...])["content"]
```

**运行**：

```bash
python3 v1_fixed_rag.py
你：你好
```

**现象**：V1 会**无脑检索**，把 3 条无关片段塞进 Prompt → 回答"世界第八大奇迹/无锡博物院/大唐不夜城"。

**这是报告里最有力的"反面案例"** —— 固定 RAG 的核心缺陷。

### 5.2 V2 Tool-RAG —— "由 Agent 决定查不查"

**代码位置**：`v2_tool_rag.py`（约 80 行）

**核心逻辑**：

```python
# RAG 封装为工具
TOOLS_SCHEMA = [..., search_travel_knowledge]

# ReAct 循环
for _ in range(MAX_TOOL_ROUNDS):
    resp = chat(messages, tools=TOOLS_SCHEMA)
    if not resp["tool_calls"]:
        return resp["content"]               # 无工具调用 → 输出答案
    for tc in resp["tool_calls"]:
        result = execute_tool(tc["name"], tc["args"])
        messages.append({"role": "tool", "content": result})
```

**运行**：

```bash
python3 v2_tool_rag.py
你：你好
你：无锡 3 日游，预算 2000
```

**现象**：
- `你好` → **不调用任何工具**，直接回答（自主判断）
- `无锡 3 日游` → 调用 `get_top_attractions` + `get_hotel_suggest` + `get_food_recommend`

**对比 V1**：节省算力，回答更聚焦。

### 5.3 V3 Agent-RAG —— "加反思"

**代码位置**：`v3_agent_rag.py`（约 180 行）

**V3 = V2 + 三个增强**：

| 增强 | 作用 |
|---|---|
| **Reranker** | 关键词重排，把最相关 chunk 排到 Top-1 |
| **缺失追问** | "帮我规划 3 天" → 反问城市 |
| **Self-Reflection** | 生成后自检，发现问题自动修正 |

**Self-Reflection 检查 5 项**：

1. **时间冲突**：同一天路线是否可行
2. **学生优惠**：涉及学生票的景点是否提示带学生证
3. **预约提醒**：需要预约的景点是否提醒
4. **避坑提示**：是否包含当地注意事项
5. **开放时间**：景点时间是否与行程匹配

**核心新增**：

```python
# 缺失追问
if self._should_ask_city(query):
    return "请问您想去哪个城市呢？"

# 自检 + 修正
for i in range(MAX_REFLECTION_ROUNDS):
    result = self._reflect(query, draft)
    if not result["has_issue"]:
        break
    draft = self._fix(query, draft, result["issues"])
```

**运行**：

```bash
python3 v3_agent_rag.py
你：帮我规划 3 天行程        # → 反问城市
你：学生党无锡 3 日游，预算 800  # → 完整分天行程
```

### 5.4 三版对比小结（报告核心素材）

| 输入 | V1 | V2 | V3 |
|---|---|---|---|
| `你好` | ❌ 无脑检索，返回景点 | ✅ 正常问候 | ✅ 正常问候 |
| `无锡灵山大佛学生票` | ✅ 检索命中 | ✅ 检索命中 | ✅ 检索命中，重排后更精准 |
| `帮我规划 3 天` | ⚠️ 猜城市 | ⚠️ 猜城市 | ✅ **反问城市** |
| `学生党无锡 3 日游` | ⚠️ 有遗漏 | ⚠️ 有遗漏 | ✅ **自检后补全** |

**注意**：以上对比在**商汤版**下效果最佳；**千问版**下 V3 的自检质量会下降，但链路一致。
